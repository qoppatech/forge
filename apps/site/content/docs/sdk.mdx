---
title: SDK
description: The @forge/sdk workspace package and what it exports today.
---

`@forge/sdk` packages the public interface of the compiled program. It is a private workspace package and is not published to npm.

```ts
import { FORGE_PROGRAM_ID, forgeIdl, type Forge } from "@forge/sdk";
```

| Export | Description |
| --- | --- |
| `forgeIdl`, `FORGE_PROGRAM_ID` | The Anchor IDL generated by the program build and its program address. |
| `ForgeIntent`, `buildForgeInstruction`, `decodeForgeInstruction` | JSON-safe intents for all nine instructions, encoded and decoded from the IDL (discriminators, layouts, account order and roles). |
| `findVaultAddress`, `findLoanAddress`, `findWithdrawalAddress`, `deriveOnchainId` | PDA helpers and deterministic 32-byte ids from business references. |
| `compileIntentTransaction`, `verifyPlan`, `signPlanTransaction`, `mergeSignatures` | Build an unsigned plan, let each signer verify the exact bytes, sign locally and merge partial signatures. |
| `decodeVaultAccount`, `decodeLoanAccount`, `decodeWithdrawalAccount` | Typed account reads. |
| `decodeTransactionError` | Maps transaction errors to Forge/Anchor/Token names and a reconciliation category (`replay`, `rejected`, …). |
| `loanView`, `parseTokenAmount`, `formatTokenAmount` | Computed expiry/overdue status and integer base-unit amounts. |

The SDK depends only on `@solana/kit`. It never accepts, stores or generates bank or borrower private keys: callers sign with their own wallet or key pair.

```ts
import { verifyPlan, signPlanTransaction } from "@forge/sdk";

const problems = await verifyPlan(plan); // decode the bytes and compare them with the intent
if (problems.length === 0) {
  const signed = await signPlanTransaction(plan.transaction, [myKeyPair]);
  await fetch(`/v1/operations/${operation.id}/signatures`, {
    method: "POST",
    body: JSON.stringify({ transaction: signed }),
  });
}
```
