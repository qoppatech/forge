---
title: SDK
description: The @forge/sdk workspace package and what it exports today.
---

`@forge/sdk` packages the public interface of the compiled program. It is a private workspace package and is not published to npm.

```ts
import { FORGE_PROGRAM_ID, forgeIdl, type Forge } from "@forge/sdk";
```

| Export             | Description                                    |
| ------------------ | ---------------------------------------------- |
| `forgeIdl`         | The Anchor IDL generated by the program build. |
| `Forge`            | The generated TypeScript type for the IDL.     |
| `FORGE_PROGRAM_ID` | The program address declared in the IDL.       |

The SDK build depends on the Anchor build. It copies the IDL and types into the ignored `packages/sdk/src/generated/` directory and emits JavaScript, declarations and JSON under `dist/`.

<Callout type="info">
  Transaction builders, typed account reads and error decoding are planned for a
  later milestone and are not implemented yet.
</Callout>
